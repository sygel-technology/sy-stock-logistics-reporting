This module adds a phytosanitary report in the stock picking module,
which can be used as a plant passport.

Configuration
=============

To configure this module, you need to:

1. Go to Settings -> Company and fill in the field phytosanitary
   reference
2. Go to the products menu of any module (e.g. Sales / Products), and
   create a product with a botanic denomination

Usage
=====

To use this module, you need to:

1. Make a sale with a product that has a botanic denomination.
2. Go to the delivery note of the sale
3. From the print menu, click on 'Phytosanitary passport' to print the
   Phytosanitary passport of the products on the delivery note.
